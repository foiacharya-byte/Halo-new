# Developer Rules

1. Treat each file as one independent layer.
2. Use the storyboard only for story, hierarchy and motion—not as a flattened background.
3. Use the exact real Vadodara photo assets. Do not generate or trace new landmark architecture.
4. Add all text in HTML. The vectors are intentionally text-free.
5. Search bar, result cards, no-result card, provider trust card, forms, points counters and ticker entries must be built in code.
6. Use CSS masks/opacity for fades. Do not sharpen, distort or upscale landmark images.
7. Keep one dominant visual event per viewport.
8. Respect reduced-motion settings.
